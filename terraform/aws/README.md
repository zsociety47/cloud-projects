Not started. This folder is the slot for shared Amazon Web Services Terraform, the same shape as [`../azure/`](../azure/).

When the first AWS project needs a shared state bucket or OpenID Connect to GitHub, start here:

```text
terraform/aws/
├── modules/
├── pipeline-foundation/
└── examples/
```

Do not put Azure files in this folder. Azure lives in [`../azure/`](../azure/).
